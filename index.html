Welcome to the Distributed System Manager!

Components:
• Servidor - Central data collection server
• Agregador - Data aggregation service
• Wavy - Sensor data generator

Instructions:
1. ✅ Server starts automatically on launch (e.g., EU-S, NA-S)
2. Start one or more Aggregators (e.g., EU-Agr01, NA-Agr01)
3. Start Wavy components (e.g., EU-Wavy01, NA-Wavy02)

Continents: EU (Europe), NA (North America), SA (South America), AF (Africa), AS (Asia), OC (Oceania), AQ (Antarctica)

Keyboard Shortcuts:
• Ctrl+Shift+S - Start Server
• Ctrl+Shift+A - Start All Components
• Ctrl+Shift+X - Stop All Processes
• Ctrl+` - Focus Terminal Input

Click on any component to view its output in this terminal.
Use the "Quick Start" buttons for automatic continent setup.
