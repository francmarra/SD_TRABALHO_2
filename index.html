Welcome to the Distributed System Manager!

Components:
• Servidor - Central data collection server
• Agregador - Data aggregation service
• Wavy - Ocean sensor data generator

Instructions:
1. ✅ Server starts automatically on launch
2. Start Maritime Aggregators (e.g., EU-Agr01, NA-Agr02, AS-Agr03)
3. Start Wavy sensors (e.g., Wavy01, Wavy02, Wavy03)

Wavy System: Wavy01-Wavy26 (global ocean monitoring sensors)
Maritime Aggregators: 28 specialized aggregators by region, ocean, and area type
Data Subscriptions: Targeted sensor data filtering per maritime research area

Keyboard Shortcuts:
• Ctrl+Shift+S - Start Server
• Ctrl+Shift+A - Start All Components
• Ctrl+Shift+X - Stop All Processes
• Ctrl+` - Focus Terminal Input
