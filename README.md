# SD_TRABALHO_2

## Configuration

1. Open `Shared/MongoDB/MongoDBConfig.cs`.
2. Set `CONNECTION_STRING` to your MongoDB connection string.
3. Set `DATABASE_NAME` to your database name.

## Running the system

1. Open PowerShell at the workspace root.
2. Navigate to the start scripts folder:

   ```powershell
   cd .\"Start Files"
   ```

3. Run the main start script:

   ```powershell
   .\startAll.bat
   ```
